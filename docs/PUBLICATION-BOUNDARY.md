# Publication boundary

This repository is an anonymized engine snapshot with fresh history. Chaos is the project identity. Sample game and faction identifiers are neutral placeholders. Third-party license notices and upstream dependency attribution are retained.

Private working histories, user-profile paths, external audit captures and private backups are not included. This snapshot does not claim that unfinished gameplay requirements or performance issues are resolved. Renamed sample protocol identifiers are not compatible with a private server expecting the original keys; use a correspondingly configured sample server. Do not connect this sample to a private production service.

No remote has been configured and nothing has been uploaded. Future checkpoints must be screened for private identities, lore names, embedded asset metadata and Git author information before publishing. Never push the private development repository's earlier history into this repository.
