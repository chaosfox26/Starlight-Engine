# Live engine dependencies

This directory contains source used by the current Starlight editor. It is not an alternate engine checkout.

Start with the [root README](../README.md) and [current dependency map](<../Starlight Documents/Current/docs/CURRENT-DEPENDENCIES.md>).

The live source is in engine, Physics, src, projects, settings and third_party/JoltPhysics. The automation folder contains retired experiments, not a current runtime dependency. Its deletion is pending; do not use its results as current build instructions.

Launch the editor through the root Launch-Starlight-Editor.cmd. Old bin/build artifacts are not the canonical editor entry point. game project files remain preserved.
